## 3. 相对 0.1.0 的兼容性

**仅追加符号，无删除、无枚举改值。** 0.1.0 的连接与录制三件套签名不变。

- 新增订阅后，`Device` 析构会取消位姿/点云订阅（0.1.0 仅 `close`）。
- protobuf 在本版为**动态链接** `libprotobuf.so`（提交说明写明临时方案）；集成方部署须带上该 so，或按当时包内符号链接安装。

`0.x` 不承诺 ABI 冻结。升级必须同步头与 `.so`。

## 6. 行为与安全

- 无身份认证；同网段可控制录制。
- 启停异步：`Ok` 只表示设备接受命令。
- 同一句柄每种订阅最多一个；重复订阅返回 `Rejected`。
- 回调在 SDK 内部（Zenoh）线程；`points` 指针仅回调期内有效。
- 同一句柄接口不可重入。

## 7. Known Limitations

- 无 IMU / 原始点云 / 图像 / 标定 / 设备状态 / 初值 / 工程路径 / 错误码订阅。
- 无重定位阶段或成功查询 API。
- protobuf 未静态隐藏，可能与集成方自带 protobuf 冲突。

## 8. 升级注意（自 0.1.0）

1. 同步替换头文件与 `liblixel_sdk.so`。
2. 部署检查 `libprotobuf.so` 是否随包提供。
3. 若已自写订阅，须遵守「每种数据一个订阅槽」与回调寿命规则。
4. 用 `xg_sdk_version()` 核对运行库为 `0.2.0`。
