# Release Note — lixel_sdk 0.2.1

## 1. 标识

| 项 | 值 |
|----|-----|
| 产品 | XGRIDS Robot SDK（`lixel_sdk`） |
| 版本 | 0.2.1 |
| 发布日期 | 2026-08-24 |
| Git SHA | `2b8acf5` |
| `XG_SDK_VERSION_*` | 0.2.1 |
| `xg_sdk_version()` | `"0.2.1"`（随头宏） |
| CMake `PROJECT_VERSION` | 0.2.1 |
| `SOVERSION` | 0 |
| 上一版 | 0.2.0（`f0c277a`） |

证据：提交说明「增加 deps/linux-arm64 编译依赖包, CMakeLists.txt 支持 LIXEL_SDK_DEPS_DIR 独立编译」。`include/xg/robot_sdk_c.h` 相对 0.2.0 仅版本宏 PATCH +1。

## 2. 范围

与 0.2.0 相同的运行时能力。本版是**构建与依赖交付**修订，不是功能版。

| 项 | 内容 |
|----|------|
| 构建 | 可用 `LIXEL_SDK_DEPS_DIR` 指向独立 deps，不依赖 scanner 源树 |
| 新增目录 | `deps/linux-arm64`（交叉/本机 aarch64 编译依赖） |
| 运行时 ABI | 与 0.2.0 相同 |

## 3. 相对 0.2.0 的兼容性

**无接口增删、无结构体字段变更、无枚举改值。** 已按 0.2.0 编译的应用在仅替换 `.so` 且头仍为 0.2.0 时，功能面等价；正式集成仍要求头与库同为 0.2.1。

## 4. 变更清单

### Added

- 构建：`LIXEL_SDK_DEPS_DIR`
- 交付：`deps/linux-arm64` 预置依赖

### Changed

- 版本宏 0.2.0 → 0.2.1

### Deprecated

无。

### Removed

无。

### Fixed

无公开缺陷修复记录（本提交为构建能力）。

## 5. 该版接口清单

与 [v0.2.0](v0.2.0.md) 第 5 节**完全相同**。无新 C/C++ 符号。

## 6. 行为与安全

与 0.2.0 相同：无认证、启停异步、回调线程、句柄不可重入。

## 7. Known Limitations

与 0.2.0 相同。仍无 IMU / 图像 / 标定 / 初值 / 错误码订阅；仍无重定位结果 API。

## 8. 升级注意（自 0.2.0）

1. 若只升级库文件，用 `xg_sdk_version()` 确认为 `0.2.1`。
2. 交叉编译 aarch64 时改用本版 `deps/linux-arm64`，不要混用 0.2.0 的依赖路径。
3. 源码级 API 无需改动。
