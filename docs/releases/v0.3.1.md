## 3. 相对 0.2.1 的兼容性

**仅追加符号与结构体，无删除已有函数，无改已有枚举数值。** 0.2.1 应用在换 0.3.1 头+库后，原录制与 pose/cloud 订阅调用方式保持。

行为差异（非破坏签名，但集成必须知情）：

- `Device` 析构除 pose/cloud 外，还会取消 IMU、原始点云、三路图像、错误码订阅。
- `xg_device_is_connected` 仍可能打一次 `checkRecordStatus`（重量级，最长约 3 s）。
- 订阅槽按**数据类型**（图像按相机）各一，互不挤占 0.2.x 的 pose/cloud 槽。

## 4. 变更清单

### Added

头注释「v0.3.0」族（本仓库随 0.3.1 首次出现）：

- `xg_subscribe_imu` / `xg_unsubscribe_imu`，类型 `xg_imu_t`
- `xg_subscribe_raw_cloud` / `xg_unsubscribe_raw_cloud`（复用 `xg_cloud_frame_t`）
- `xg_subscribe_image` / `xg_unsubscribe_image`，类型 `xg_camera_id_t`、`xg_image_frame_t`
- `xg_get_camera_calib` / `xg_get_imu_calib` / `xg_get_lidar_calib`
- `xg_get_device_info`，类型 `xg_device_info_t`

头注释「v0.3.1」族：

- `xg_set_loc_init_pose`，类型 `xg_init_pose_t`
- `xg_get_data_path`，类型 `xg_data_path_t`
- `xg_subscribe_err_code` / `xg_unsubscribe_err_code`，类型 `xg_err_code_entry_t`、`xg_err_code_frame_t`

C++ 一一对应：`Device::Imu`、`subscribeImu`、`subscribeRawCloud`、`CameraId`、`ImageFrame`、`subscribeImage`、`CameraCalib` / `ImuCalib` / `LidarCalib`、`DeviceInfo`、`InitPose`、`setLocInitPose`、`getDataPath`、`ErrCodeFrame`、`subscribeErrCode`。

### Changed

- 对外版本字符串 0.2.1 → 0.3.1；CMake 工程号写成 0.3.0（错误，见 Known Limitations）
- README 增加 0.3.x 能力说明（历史稿曾误标图像为「计划中」，以头文件为准）

### Deprecated

无公开废弃符号。设备 `ModelingState` 311/312 重定位态已在 SDK 映射里标 deprecated，归为 `Error`，**不是**本 SDK 的重定位 API。

### Removed

无。

### Fixed

无单独缺陷清单随本提交发布。

## 6. 行为与安全

- 无身份认证。
- 启停异步；Timeout 时禁止直接重发，须先 `queryRecordStatus`。
- 同一句柄不可重入。
- 回调在 SDK 内部线程：`Pose` 约 100 Hz，`Imu` 约 200 Hz，reloc 点云约 1 Hz，图像默认约 2 fps（设备编码配置）。
- `CloudFrame.points`、`ImageFrame.jpegData`、错误码 `entries`（C）仅回调期内有效。C++ `ErrCodeFrame` 在桥接时已拷贝到 `std::vector`，回调返回后 vector 仍由调用方对象持有至回调结束。
- `setLocInitPose`：`Ok` = 设备 JSON `code==0`；定位未启动时设备仍可能回成功而丢弃初值。四元数模长须 > 0.1。

## 7. Known Limitations

1. **无重定位阶段/结果 API。** 设备 `RelocOutType`（分数、overlap、是否全局初始化、reloc 位姿）未上线；`m_relocSuccess` 只给飞行 MQTT。
2. **`Pose.isLocal` 不可信。** 设备已写 `is_local`，SDK 自带 proto 无该字段，反序列化恒为 0（有图）。
3. **`setLocInitPose` 成功 ≠ 已定位到地图。** 只是先验。
4. **CMake 0.3.0 vs 头 0.3.1** 未在本版修正。
5. `getCameraCalib(camera_id)` 与 `subscribeImage(CameraId)` **不是同一套编号**。
6. `getDeviceInfo` 不映射设备 JSON 中的 `battery.type/cycle`、`cpu_loads`、`rtk.navsat_status`。
7. 无认证；须独立 VLAN。

## 8. 升级注意（自 0.2.1）

1. 同步替换 **全部头文件** 与 `liblixel_sdk.so`，禁止混用。
2. 用 `xg::sdkVersion()` / `xg_sdk_version()` 断言 `"0.3.1"`，不要用 CMake 工程号判断运行库。
3. 新增订阅须处理 `Rejected`（槽已被占）与回调寿命。
4. 需要重定位成功判定的产品：本版做不到，不要用 `isLocal` 或 `setLocInitPose` 的返回值代替。
5. 图像已可用，不要再按 0.2.x README「计划中」集成。
