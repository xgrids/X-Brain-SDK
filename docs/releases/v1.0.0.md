## 3. 相对 0.3.1 的兼容性

**本版含对外行为变更（Breaking），无删除已有函数、无改已有枚举数值。** 头文件符号集与 0.3.1 一致，但两处**运行期语义**变更需集成方知情，见下方 Changed。

## 4. 变更清单

### Changed（对外行为变更，须知情）

1. **`Options.port` 语义变更 + 连接拓扑简化（本版核心）**
   - 旧（0.3.x）：`Options.port` 是 `robot_app` 端口（默认 **7447**），SDK 内部再按 `port+1` 连 `modeling_app`(7448)，即同时连两个端点。
   - 新（1.0.0）：`Options.port` **直接是 `modeling_app` 的端口**（默认 **7448**）。SDK **只连 modeling_app 一个端点**，不再连接 `robot_app`(7447)。
   - 依据：SDK 需要的数据面（`device_locate`/`reloc_device_cloud`/`raw_imu`/`raw_pointcloud`/`camera/*`/`err_code`）与命令面（`robot_cmd` queryable）都由 modeling_app 在同一个 zenoh session 内提供；`robot_app`(7447) 的 `ptz_capture` 本 SDK 不使用。去掉 7447 后少一个无用连接，并缩小「填错 IP 静默连到同网段其他设备」的风险面。
   - **集成方影响：**
     - `Options.port = 0`（用默认）的集成方：**无感**，默认值自动从 7447 变为 7448。
     - 显式传过 `7447` 的集成方：**必须改**为 `0` 或 `7448`，否则 SDK 会去连 7447（modeling_app 不在该端口）而超时。
     - 旧设备 `modeling_app` 落在随机端口 X 时：旧版传 `X-1`，新版**直接传 `X`**。
   - `XG_DEFAULT_PORT` 宏由 `7447` 改为 `7448`。

2. **对外位姿/点云坐标系切换为设备(IMU)系（承 0.3.x→1.0.0 迁移）**
   - `subscribePose` 订阅 key 由 `body_locate`（Body 系）改为 **`device_locate`（IMU 系）**。
   - `subscribeCloud` 订阅 key 由 `reloc_body_cloud` 改为 **`reloc_device_cloud`（IMU 系）**。
   - 这是坐标系层面的破坏性变更：位姿原点/朝向、点云坐标系改变，载体（狗/车等）安装变换由集成方自行计算。详见 [api_reference_v2.md](../api_reference_v2.md) §3.1 / §3.3 与设备端 `coordinate_frames.md`。
   - **需设备端固件已发布 device 系 key**（modeling_app 的 `publishDeviceLocation`/`publishDeviceCloud`）。

3. 对外版本字符串 0.3.1 → 1.0.0；CMake 工程号、`XG_SDK_VERSION_*`、`xg_sdk_version()` 三处对齐为 1.0.0。

## 5. 行为与安全

- 无身份认证；须独立 VLAN、同网段直连。
- 启停异步；Timeout 时禁止直接重发，须先 `queryRecordStatus`。
- 同一句柄不可重入。
- 回调在 SDK 内部线程：`Pose` 约 100 Hz，`Imu` 约 200 Hz，reloc 点云约 1 Hz，图像默认约 2 fps（设备编码配置）。
- `CloudFrame.points`、`ImageFrame.jpegData`、错误码 `entries`（C）仅回调期内有效。
- `setLocInitPose`：`Ok` = 设备 JSON `code==0`；定位未启动时设备仍可能回成功而丢弃初值。四元数模长须 > 0.1。

## 6. Known Limitations

1. **无重定位阶段/结果 API。** 设备 `RelocOutType`（分数、overlap、是否全局初始化、reloc 位姿）未经 SDK 上线。
2. **`Pose.isLocal` 不可信。** 反序列化恒为 0。
3. **`setLocInitPose` 成功 ≠ 已定位到地图。** 只是先验。
4. `getCameraCalib(camera_id)` 与 `subscribeImage(CameraId)` **不是同一套编号**。
5. `getDeviceInfo` 不映射设备 JSON 中的 `battery.type/cycle`、`cpu_loads`、`rtk.navsat_status`。
6. **device 系 key 依赖设备端固件**：若设备固件未发布 `device_locate`/`reloc_device_cloud`，位姿/点云订阅将 0 帧（其余数据不受影响）。

## 7. 升级注意（自 0.3.1）

1. 同步替换 **全部头文件** 与 `liblixel_sdk.so`，禁止混用。
2. **检查 `Options.port` 用法**：显式传 `7447` 的代码改为 `0` 或 `7448`；传 `0` 的无需改。
3. **确认设备端固件已发布 device 系 key**（`device_locate`/`reloc_device_cloud`），否则位姿/点云 0 帧。
4. 位姿/点云坐标系已切为设备(IMU)系，若此前按 Body 系做过载体变换，需重新核对。
5. 用 `xg::sdkVersion()` / `xg_sdk_version()` 断言 `"1.0.0"`。
